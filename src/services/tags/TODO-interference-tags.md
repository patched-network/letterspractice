# TODO: Interference Concept Tags

## Context

WST focus-group cards (generated by `generate-cards.ts`) emit `concept:interference:*` tags:

```
concept:interference:visual          — broad category
concept:interference:mirror-bd       — specific group
concept:interference:rotation-un     — specific group
concept:interference:voicing         — broad category
concept:interference:voicing-fv      — specific group
... etc (12 groups total, see WST_FOCUS_GROUPS in generate-cards.ts)
```

These tags are **not yet registered** in `conceptTags.ts` `CONCEPT_TAGS` and are **not consumed** by any navigator strategy.

## How they differ from existing concept tags

Existing concepts are properties of a *single* GPC entry (derived via `conceptTagsForGpc(entry)`). Interference tags describe *relationships between* GPC entries — they tag cards that deliberately pair confusable letters.

## Options for integration

1. **Register explicitly in CONCEPT_TAGS** — Adds them to the closed const tuple + `CONCEPT_TAG_SET`. Provides compile-time checking. Downside: every new focus group requires updating two files (generate-cards.ts + conceptTags.ts).

2. **Separate namespace / registry** — New file (e.g., `interferenceTags.ts`) with its own registry. Keeps the existing concept taxonomy clean. Interference tags get their own utilities for construction/parsing.

3. **Leave informal, formalize later** — They're just strings on card docs today. Navigator strategies can match by prefix (`/^concept:interference:/`). Formalize when a strategy actually needs to consume them. This is the current state.

## What needs to happen for them to be useful

A navigator strategy needs to reference them — likely an update to the `interference.json` strategy config (generated by `generate-strategy-configs.ts`) to gate focus-group WST cards until both members of a confusable pair are individually stable.

## Breadcrumbs

- Tag generation: `content/phoneticAnalytics/scripts/generate-cards.ts` → `WST_FOCUS_GROUPS` + focus group card loop
- Tag registry: `src/services/tags/conceptTags.ts` → `CONCEPT_TAGS`
- Strategy configs: `content/phoneticAnalytics/scripts/generate-strategy-configs.ts`
- Strategy config output: `content/phoneticAnalytics/outputs-v2/strategy-configs/interference.json`
